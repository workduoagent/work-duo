## 小分队工作台：右栏悬浮窗切 Tab 卡顿（性能优化，未提交待验证）

现象：工作台右侧悬浮面板切换「成员状态 / 团队记忆 / 决策」时明显顿挫。

定位（SquadDetailPage.tsx 单文件 800+ 行、状态全在父组件）：
1. 任一 setState 都触发整页重渲染 → 时间线每条气泡重跑 react-markdown 全流程（gfm+katex+highlight+mermaid）；
2. `agentAppearanceOf(agents, id)` 在库内无 appearance 时现场生成新对象，击穿 `PixelAgent` 的 memo，每次重渲染重建数百个 rect；
3. 运行中有 `setInterval(setNow, 1000)` 每秒整页重渲染（仅为顶栏计时）；
4. `sceneSVG(mode)` 每次渲染重建整幅像素场景 SVG 字符串；
5. `.sw-aside-float` 用 `filter: drop-shadow`，面板内容一变就对半屏区域重做滤镜光栅化。

改动（前端，刷新即生效）：
- `MarkdownRenderer` 改为 `memo` 导出（content 未变即跳过解析管线）——全局生效。
- 新增 memo 子组件 `CrewBar` / `StageView` / `TimelineView` / `AsideFloat`，父组件只留骨架；
  Tab 与团队记忆数据下沉到 `AsideFloat`（父用 `asideReq{tab,n}` 请求切页），切 Tab 不再碰时间线。
- 顶栏计时抽 `LiveTimer` 自持 tick，移除父级 `now` 与两个 interval 里的 setNow。
- `appearanceOf` 按 agentId 缓存外观引用；`sceneHtml` 用 useMemo。
- `gateCall/handleInject/pickMember/closeChatCard` 改 useCallback（内联箭头会造新 props 击穿 memo），
  门禁/交付的 sessionId 统一在 gateCall 内补齐。
- SCSS：右栏 `filter: drop-shadow` → `.sw-aside-panel` 的 `box-shadow` + `contain: paint`。

验证：`node node_modules/typescript/bin/tsc --noEmit` 通过；未提交（待用户真机复测确认）。
