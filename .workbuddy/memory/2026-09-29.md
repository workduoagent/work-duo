## 🎨 工作台五修（22:2x~22:4x，8448db3，用户实测反馈）
1. **气泡 Markdown 松散**：root.scss 的 .md-body 全局 rem 级间距渗进气泡（p 0.75rem/h2 1.5rem）——
   `.sw .sw-md` 双类提权全面覆盖（p 5px/h 7-4/li 2px/首尾清零）。
2. **对话不自动滚**：sw-timeline 贴底跟随三态（贴底跟随/上滚暂停/滚回底部恢复，距底 48px 阈值）；
   生效点=轮次/汇总/门禁卡变化。
3. **左栏卡片不适配暗色**：16 条 `.dark` 覆盖（is-selected 浅蓝底/mode-tab/徽标全系/门禁卡/高亮
   气泡/用户头像底）——项目主题机制=html.dark 类 + `.dark &` scss 嵌套（chat.scss 同款）。
4. **打字机流式**：TypewriterBubble——仅事件实时推来的新轮打字（BoardRound 加 fresh 标记，
   事件 push 带 fresh:true / mapper 历史回放不带）；~1.6s 均匀打完（step=max(2,len/140)@16ms）+
   光标闪烁；打字阶段纯文本、完成后切 Markdown；fresh 快照进 useState 初始化器防父级重渲染
   重启；metrics/handoff/JSON 结构化轮不打字；prefers-reduced-motion 冻结。
5. **计时 NaN:NaN:NaN**：createdAt 是 ISO 串（safeIso），Number() 直转 NaN——Date.parse+
   isFinite 守卫归零。**同类隐患**：凡 safeIso 字段禁 Number() 直转。
- 教训：滚动 effect 引用后声明 state（planPending）→ TS2448——**插入代码块前先核对该位置
  之前已声明的符号集**。

- **气泡排版二轮压缩 + 代码块主题化（23:0x）**：用户反馈行距仍大+代码块白天看不清。
  ①再压一档（line-height 1.5/p 4px/li 1px/h 6-3）；②根因=pre 与 sw-code 硬编码深底
  浅字（#1e1e2e），白天模式下 --hljs-* 白天深色 token 糊在深底上——改走
  --color-code-bg/fg/border 令牌（白天浅底深字/暗色深底浅字）。教训：**配色必须走令牌，
  硬编码深浅底会破坏另一侧主题的语法高亮**。
