# 2026-08-26 工作日志

## TopBar 胶囊菜单重构（v2 最终版）
- **文件**: `src/components/layout/TopBar.tsx` + `src/styles/layout.css`
- **关键决策**：放弃 Appica Navigation 组件，改用**纯 HTML `<button>` + 自有 CSS** 实现胶囊菜单
  - 原因：Appica Navigation pill 的内部样式（::before 背景、cva 变体类）与自定义底槽/滑块样式在 Tauri WebView 中存在层叠冲突，导致样式不生效
  - 纯 HTML 方案零依赖冲突，完全控制 DOM 和样式
- **实现**：
  - 底槽轨道：`border-radius: 999px` + `background: var(--color-border-muted)`（亮/暗两态清晰可辨）
  - 滑块：JS 测量选中项 → CSS 变量 `--pill-x/--pill-w` → `transform + width` 过渡
  - 动画：cubic-bezier(0.32, 0.72, 0, 1) 420ms（iOS 分段控件曲线）
  - 6 项一级菜单：LLM / MCP / Skill / 智能体 / 小分队 / 设置
  - 图标：@appica/icons-react（Sparkles/Plug/Wand/Brain/Users/Settings）
  - 健壮性：首帧不过渡 / ResizeObserver / 字体加载重测 / reduced-motion 降级
  - 暂为本地高亮态，未接路由
- **构建产物变化**：CSS 33.4KB → 30KB（去掉 Appica Navigation 依赖），JS 638KB → 627KB
