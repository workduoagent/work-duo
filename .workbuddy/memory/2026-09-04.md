## 修复 SOL 任务「子任务超过 5 轮仍未闭环」（Agent.log 第二轮失败）

## 功能：停止按钮即时取消后台任务
用户要求点击输入框"停止"后后端立即终止任务。原 `cancel_agent_task` 是空壳（`let _ = runtime; Ok(())`），流水线无任何取消检测。实现真正的取消信号链（cargo check exit 0）：
- **运行时共享标志**：`runtime.rs::AgentRuntime` 新增 `cancel_flag: Arc<AtomicBool>`；`run_task` 开头 `store(false)` 清除上轮残留；`run_simple_chat`/`run_pipeline` 透传该标志。
- **流式断流核心**：`call_llm_stream` 新增 `cancel` 参数，SSE 读取循环每 chunk 前检测，命中即 `break` 断流（连接随函数返回丢弃）。
- **流水线取消**：`pipeline.rs::run_subtask` 循环顶部 + 流式返回后两处复检；`run_pipeline` 步骤开始前 + 重试循环内（子任务 `cancelled` 时**跳过失败重试**整体收尾，避免把取消误判为失败重试 3 次）两处复检；`SubTaskOutput`/`PipelineResult` 加 `cancelled` 字段。
- **run_task 收尾**：规划后、流水线后检测 `cancelled` → emit `⛔ 任务已被用户取消` + `emit_task_done` 提前收尾，不持久化半成品 round。
- **命令层**：`commands.rs::cancel_agent_task` 由空壳改为 `cancel_flag.store(true)`。前端 `useAgentSession.ts:315` 已 `invoke('cancel_agent_task')`，链路完整。
**生效**：仅 Rust 改动，需 `npm run tauri` 重编后端。已补记到架构文档对照表（不入本节文档正文）。
