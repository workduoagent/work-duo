# 故障复盘模板（RCA）

```markdown
# INC-<yyyymmdd> <标题>

| 项 | 内容 |
|---|---|
| 影响 | |
| 发现/恢复时间 | |
| 责任人 | |

## 时间线
## 现象与影响面
## 根因（5 Whys）
## 为何没被拦住
## 修复项
## 预防项
## 跟踪与验证
```

## 纪律

1. 对事不对人；禁止只写「操作失误」。  
2. 预防项必须可落地（用例/门禁/监控/设计）。  
3. 与群聊 `squad-chat-incident-rca` 收口字段对齐：`rootCauses fixItems preventions`。
