# kb-pitfalls · 历史缺陷与踩坑（知识库种子）

> 用途：防再犯——已知坑、回归清单、事故复盘结论。  
> 挂载：全员；QA/评审优先召回。

## 语料清单

| 文件 | 内容 |
|---|---|
| `01-pitfall-record.md` | 踩坑记录模板 |
| `02-known-pitfalls.md` | 本产品常见坑（可迭代） |
| `03-regression-checklist.md` | 回归清单 |
| `04-incident-review.md` | 故障复盘模板 |

## 使用

1. 修复缺陷必须留一条 pitfall 或回归项。  
2. 评审时对照 `02` 与 `03`。  
3. 与记忆 `fix` 锚定互补：本库可审计，记忆可召回。
