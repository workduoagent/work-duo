# 已知踩坑（可迭代）

> 首发为「跨智能体研发团队」通用坑，可按你们产品实测不断追加。

## 通用

| 坑 | 现象 | 预防 |
|---|---|---|
| 契约只在聊天 | 前后端字段对不上 | 契约文件进 inputs/交付包 |
| 只测 happy path | 上线后边界炸 | 每功能至少 1 失败用例 |
| 假完成 | 描述做完但无文件 | expectedArtifacts 对账 |
| 密钥入库 | 扫描出 token | 规范检查 + 提交门禁 |
| 迁移不幂等 | 二次执行失败 | IF NOT EXISTS + 双轨 |

## 前端

- 未过 typecheck 就合并  
- 绕过 UI 封装导致主题不一致  
- 组件直写 SQL / 裸 IPC

## 后端

- 吞异常只 log "error"  
- 无超时 HTTP/子进程  
- 接口 200 包错误语义

## 多智能体协作

- 评审角色可写代码导致越界  
- 交接传全文导致截断与贵  
- 沙箱被误当安全边界  
- 宿主工具链无白名单被拼命令
