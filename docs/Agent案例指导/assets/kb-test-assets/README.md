# kb-test-assets · 测试资产库（知识库种子）

> 用途：用例模板、自动化结构、缺陷模式、门禁标准。  
> 挂载：QA、开发自测、评审对照。

## 语料清单

| 文件 | 内容 |
|---|---|
| `01-test-plan-template.md` | 测试计划模板 |
| `02-case-library-patterns.md` | 常用场景模式库 |
| `03-automation-layout.md` | 自动化目录与命名 |
| `04-release-gate.md` | 发布门禁标准 |

## 使用

- 新特性用例从模式库裁剪，而不是从零空想。  
- 自动化脚本路径写入用例表，形成双向索引。  
- 门禁以 `04-release-gate.md` 为准，与 `skill-delivery-pack` 一致。
