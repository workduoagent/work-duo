# 用户故事与验收写法

## 用户故事格式

```text
作为 <角色>
我希望 <能力>
以便 <价值>
```

示例：

```text
作为 运营
我希望 导出带统计字段的订单报表
以便 对账时不用二次计算
```

## 验收标准（AC）

### 推荐格式（Given/When/Then）

```text
AC-1 导出成功
Given 用户已登录且有导出权限
When 选择时间范围并点击导出
Then 生成 xlsx，且包含 orderCount/amountSum 字段
```

### 清单格式

```text
AC-1 [ ] 空结果时提示「无数据」且不生成文件
AC-2 [ ] 超过 10 万行提示分批或异步
AC-3 [ ] 无权限用户按钮置灰并有说明
```

## 规则

1. AC 编号稳定，全链路引用（用例/交付包）。  
2. 每条 AC 只验证一件事。  
3. 必须含失败/边界路径。  
4. AC 与接口契约字段名可对上。
