# PRD 标准模板

```markdown
# <功能名> PRD

| 项 | 内容 |
|---|---|
| 版本 | v1.0 |
| 日期 | YYYY-MM-DD |
| 作者 | |
| 状态 | 草稿 / 评审中 / 已定稿 |

## 1. 背景与问题
## 2. 目标
## 3. 非目标（明确不做）
## 4. 用户与场景
## 5. 用户故事
## 6. 功能范围
## 7. 验收标准（AC）
## 8. 交互/数据要点（可链到契约）
## 9. 风险与依赖
## 10. 优先级与里程碑
## 11. 开放问题（待确认）
```

## 写作规则

1. **非目标**必须写；防止范围膨胀。  
2. 验收标准可测，禁止「体验好」「性能高」。  
3. 不确定事实标「待确认」，禁止臆造业务数据。  
4. 与契约冲突时，以评审后的契约为准并回写 PRD。
