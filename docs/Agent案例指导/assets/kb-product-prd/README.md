# kb-product-prd · 产品需求与验收（知识库种子）

> 用途：需求事实源——PRD、用户故事、验收标准、变更记录。  
> 挂载：PM、架构、QA、集成；开发读验收与范围。

## 语料清单

| 文件 | 内容 |
|---|---|
| `01-prd-template.md` | PRD 标准模板 |
| `02-user-story-acceptance.md` | 用户故事与验收写法 |
| `03-change-request.md` | 变更/裁决记录模板 |
| `04-feature-sample-export.md` | 样例：导出统计需求（可复用作练习） |

## 使用方式

1. 新需求按模板建档，放入本库对应特性目录。  
2. 验收 ID（AC-xx）全链路引用到用例与交付包。  
3. 范围变更走变更记录，不改历史原文，只追加。
