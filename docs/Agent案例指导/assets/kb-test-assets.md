# 2. 常用场景模式库

按模块裁剪，不必全测。

## 列表/分页

- 空数据、单条、满页、跨页
- 非法 page/size
- 排序与筛选组合
- 权限过滤

## 表单

- 必填校验、格式校验、重复提交
- 边界长度、特殊字符、XSS 载荷
- 保存失败回滚

## 导出/导入

- 正常导出、空结果、超大、非法格式导入
- 字段完整、编码（UTF-8/GBK）
- 权限与水印/脱敏

## 权限

- 未登录、无权限、越权访问
- 按钮/接口双验证

## 异步任务

- 提交、进度、成功、失败重试、取消
- 超时与幂等

## 状态机

- 合法迁移、非法迁移、并发迁移

# 3. 自动化目录与命名

```text
tests/
  cases/<module>/TC-<module>-<id>.md
  e2e/<module>/
  api/<module>/
  reports/
```

## 命名

- 用例 ID：`TC-<module>-<seq>`
- 脚本：`test_<domain>_<behavior>.py` 或 `*.spec.ts`
- 报告：`YYYYMMDD-<feature>.md`

## 原则

1. 脚本与用例 ID 可互相检索。  
2. 测试数据自造自清，不依赖脏环境。  
3. 断言明确：状态码、错误码、关键字段。  
4. 禁止无断言冒烟当「已测」。

# 4. 发布门禁标准

## 必须（全绿才放行）

| 门 | 标准 |
|---|---|
| 构建 | typecheck / compile / build 通过 |
| 测试 | P0/P1 无失败；无未决 error |
| 评审 | Blocker 清零 |
| 验收 | AC 全覆盖或显式 skip+理由 |
| 交付包 | manifest 与文件一致 |

## 建议

- 覆盖率不低于项目基线（如有）
- 性能关键路径有基线对比
- 变更日志已生成

## 例外

- 带风险放行必须：责任人、风险说明、补测计划、过期时间
