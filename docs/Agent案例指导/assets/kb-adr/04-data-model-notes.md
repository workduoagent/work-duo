# 数据建模备忘

## 原则

1. 概念清晰优先于表多；避免过早分库。  
2. 主键策略全项目一致（uuid / snowflake / 自增）。  
3. 金额用整数分或 Decimal，禁浮点。  
4. 时间统一 UTC 存储，展示再转。  
5. 软删 vs 硬删写进 ADR。

## 表设计检查

- [ ] 是否有唯一约束与必要索引  
- [ ] 变更是否幂等（`IF NOT EXISTS`）  
- [ ] 是否双轨（init/updater）同步  
- [ ] 预留扩展字段是否必要（避免 JSON 塞一切）

## 迁移

- DDL 进版本文件，禁止口头改库。  
- 回滚脚本或回滚说明存在。  
- 破坏性迁移需停机/双写方案。
