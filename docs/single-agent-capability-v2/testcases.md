# 单 Agent 能力用例目录 v2（可执行，55 例）

> 面向**真实工作场景**的能力编排测评，是 v1（`../single-agent-capability`）的二次补充与扩展。
> 每条用例：ID / 步骤要点 / 自动断言（runner 端 ground-truth）/ 人工评分点。
> 执行：`node run_capability_suite_v2.mjs run --ids <ID>` 或 `run --suite <套件>`。

**与 v1 的分工**：v1 测引擎单点能力（意图/规划/ReAct/校验/恢复/上下文/生命周期，D1–D8）。
v2 测**场景化编排**——对话/编码/办公/数据/记忆/知识库/插件/技能/对抗 + 旗舰 E 系列「单智能体整体编排」。
两套共用 `agent_task_driver.mjs` 标准库与评分框架，资产前缀区分（v2 一律 `cap2-`）。

**v2 的三个「更进一步」**：
1. **runner 端独立 ground-truth**：T/E 系列数值由 runner 用 node 重算比对，不信任模型自报；
   二进制产物验魔数（xlsx=PK、png=PNG 头），「手写二进制假成功」直接现形。
2. **复用 workduo-mcp L2 seeds**：K 系列直接装载 19 个真实缺陷种子项目（ReDoS/月份 0 基/跨文件对账…），
   出题即真实工程事故。
3. **对抗与纪律维度**：X 系列把提示注入、越权删除诱饵、沙箱离线纪律做成可回归用例。
