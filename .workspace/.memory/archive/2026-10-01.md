# 2026-10-01

## 修复：启动创建 Python 环境失败（清华 anaconda 镜像 403）

- 现象：启动/点「创建环境」报 `创建 Python 环境失败（退出码 1）`，libmamba `Transfer finalized, status: 403 https://mirrors.tuna.tsinghua.edu.cn/anaconda/.../repodata.json`，全部 subdir not loaded。
- 根因：TUNA 的 anaconda 镜像对 micromamba 这类非浏览器 UA 直接 403（HTML 提示「您访问使用的软件带有非常用软件的特征」）；`.mambarc` 原先**写死清华源**。实测：清华 403 / 中科大 200 / 官方 repo.anaconda.com 200 / 阿里·腾讯 404（路径已下线）。
- 改动（`src-tauri/src/mamba_manager.rs`）：
  - 新增镜像源档案 `MIRRORS`（ustc → tuna → official）+ 探活选源 `ensure_mambarc`（先 `WD_MAMBA_MIRROR` 强制，再进程内缓存，再复用已有 rc 并探活，最后顺序探活；全挂则保留原文件）。`.mambarc` 加标记行 `# workduo-mamba-mirror: <id>` 用于识别/换源。
  - 新增 `run_mamba_with_mirror_fallback`：命令失败且判为镜像类故障（403/404/repodata/Subdir/Transfer finalized/Connection/timeout）→ 拉黑当前源、换源后重试一次。接入 create（init/reset/ensure_default_env）与 install（命令 + selfheal 静默安装）。
  - `MambaManager::setup` 改为 `async`（首次探活），同步更新 11 处内部调用 + `plugin_runner.rs:740`。
  - 单测 3 条：rc 标记往返、默认源非清华、镜像故障判定不误伤 ModuleNotFoundError/SyntaxError。
- 验证：`cargo check` 与 `cargo check --tests` 均零错误；micromamba 用中科大 rc `--dry-run` 解出 python 3.11.16（20 包 / 37MB）成功。
- 注意：**Rust 改动需重启 App 才生效**；已预写 `src-tauri/target/debug/.mambarc` 为中科大版本。
