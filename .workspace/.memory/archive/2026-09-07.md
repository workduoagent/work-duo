## 修复：ArtifactCanvas 拖拽平移崩溃（Cannot read properties of null reading 'vbX'）
- 现象：智能体会话页「画布」拖拽节点/画布时白屏崩溃，堆栈指向 `ArtifactCanvas.tsx` 的 `setViewBox` updater 读 `dragRef.current!.vbX`。
- 根因：在 `setState` 的 updater 函数里读取 `dragRef.current`；`mouseup` 先置 `dragRef.current = null`，React 随后才执行排队的上一次 `mousemove` 的 updater → 读 null 崩溃（React 18 updater 晚于事件回调执行 + 自动批处理导致的竞态）。
- 修复：`mousedown` 时把 `viewBox.w/h` 一并快照进 `dragRef`；`onSvgMouseMove` 改用快照 `drag` 直接计算并传普通对象给 `setViewBox`，依赖改为 `[]`，彻底不在 updater 读 ref。`onSvgMouseDown` 依赖补全 `viewBox.w/h`。
- 校验：`npm run typecheck` 零错误。
- 设计说明：节点（`<g data-node>`）本身不可拖动，仅为只读 DAG 布局；可拖动的是画布平移（mousedown 落在空白 SVG 区域时）。
