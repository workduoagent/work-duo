## 结论与坑

- 生图模型不能当大脑（引擎约定大脑须 text/multimodal），生图走 `native__generate_image` 工具，有启用的 image 模型即自动注册。
- mermaid v10.5+ 语法错误默认把炸弹图 append 到 body——必须 `suppressErrorRendering: true`。
- 模型输出图表常写成 ` ```json ` 而非 ` ```echarts `，靠结构识别兜底；非法 JSON（如数据数组里混入垃圾 token）不渲染、回退代码高亮。
- git mv 对中文目录名在 Git Bash 会失败，用 Python shutil.move + 提交时重命名检测代替。
- tauri WindowConfig 字段类型不一致：width/height 是 f64，min_width/min_height 是 Option<f64>。
