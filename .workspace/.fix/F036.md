# F036 · 30 个 CSS 变量被引用但从未定义——主题令牌半失效

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §3.1
- 位置：`chat.scss 20+ 处、PixelAgent.scss:120-130（comm 实测清单见报告）`
- 级别：P1 严重·UI
- 状态：**待修复**

## 问题与影响

均带 fallback 编译不报错、缺陷被掩盖——换主题这批文字永不变色；fallback 是 antd 旧蓝 #1677ff 与 Ocean 调色板 #0ea5e9 不一致 → chat 页与其它页两套主色。

## 修复方案

variables.scss root 补齐映射（--color-primary: var(--color-brand-600) 等），再全局删 fallback。

## 验证

5 套主题切换全页统一变色；无 fallback 依赖。
