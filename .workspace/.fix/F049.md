# F049 · 沙箱脚本执行无取消能力

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §3.14
- 位置：`sandbox/python:377、sandbox/node:230、squads:1663`
- 级别：P2·UX
- 状态：**待修复**

## 问题与影响

无法中止跑飞的脚本，只有 disabled={running}。

## 修复方案

Rust 加 run_id + cancel_script，运行中按钮换「停止」。

## 验证

修复后按 `.norms` 对应检查命令回归（前端 typecheck / Rust cargo check）。
