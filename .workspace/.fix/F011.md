# F011 · squad 启动清扫会误杀正在运行的会话

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.11
- 位置：`src-tauri/src/agent/squad/squad_orchestrator.rs:2423-2425`
- 级别：P1 严重·正确性
- 状态：**待修复**

## 问题与影响

UPDATE ... SET status='failed' WHERE status IN ('running','awaiting_*','paused') 无条件全表、无进程归属判定（SQUAD_CANCELS 内存表才是真相源但查询不看它）。再次触发清扫会把正在跑的 session 改 failed，协程不知情继续写 round；极端时序 resume 后两协程同跑一 session 互相覆盖 board。

## 修复方案

改为 WHERE id NOT IN (活跃注册表)，或引入 process_id 列做归属判定。

## 验证

运行中触发清扫不影响活跃 session；崩溃遗留 session 仍被正确标记。
