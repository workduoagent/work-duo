# F009 · execute_command 走 cmd /C 整串透传

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.9
- 位置：`src-tauri/src/agent/engine/native/exec.rs:549-556`
- 级别：P1 严重·安全
- 状态：**待修复**

## 问题与影响

command 来自模型输出零转义直接交给 cmd /C——等价于把 shell 交给 LLM（可 cd ..、读工作空间外任意文件）。缓解：60s 硬超时 + 沙箱模式不注册，但宿主模式一次诱导即可任意命令。

## 修复方案

宿主模式同样不给 shell：改受限命令执行器（argv 白名单）或前置黑名单过滤（禁 ..、禁绝对路径、禁嵌套 shell）；host/exec.rs:23 的 sq() 转义是正确参照。

## 验证

宿主模式注入类命令（嵌套 shell/越径读取）被拒；白名单命令正常执行。
