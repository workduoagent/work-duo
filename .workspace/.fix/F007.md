# F007 · runtimeStore 事件路由无 run 归属校验

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.7
- 位置：`src/pages/agent-studio/session/runtimeStore.ts:574-578`
- 级别：P0 致命·正确性
- 状态：**待修复**

## 问题与影响

所有事件无条件写入「当前 running 会话」；切换会话后第二个 beginRun 覆盖 runningSessionId，前一 run 的终态事件写入新会话条目，UI 显示错乱。

## 修复方案

Rust 事件 payload 补 session_id，前端按 id 路由，不匹配即丢弃。

## 验证

双会话并发 run 时事件各归各会话，切换无串扰。
