## 使用约定

1. **一个问题一个 `F<序号>.md`**：含 问题与影响 / 修复方案 / 验证 三要素；修完把状态改为 `已修复（<commit>）`，不做标 `不复修（理由）`。
2. **修复前先复核**：走查是静态检索 + 抽查复核的产物，动手前按文件内「验证」小节先复现实测，坐实再改（误报就把状态改 `误报已核实` 并注明证据）。
3. **纪律**：按 `.norms/` 执行；每个修复独立 commit（`fix(F0xx): ...`），验证结论写进 commit 正文。
4. **报告类新增**：下次全量走查的报告原文同样放本目录，拆单后原文件保留作溯源。
