# F017 · events.rs 裸 lock().unwrap + 持锁深拷贝

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.17
- 位置：`src-tauri/src/agent/events.rs:377、:389（同文件 :83 是正确写法）`
- 级别：P1 严重·可靠性
- 状态：**待修复**

## 问题与影响

Mutex 毒化后这两处永久 panic（调用点是终态 trace 回填 → 轨迹思考/工具列永久为空）；且持锁 clone 整个事件 Vec，push_event 被阻塞——事件总线成全局串行瓶颈。

## 修复方案

改 unwrap_or_else(|e| e.into_inner())；std::mem::take 后出锁再序列化。

## 验证

毒化注入不再 panic；事件高频期 push 无明显阻塞。
