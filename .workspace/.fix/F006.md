## 问题与影响

upsertAgent(payload as AgentUpsertInput) 等编译期断言；patch.segments 直接流入 segments_json 并被 message-ui 当 ChatSegment[] 渲染——外部客户端可注入任意形状 JSON 造成渲染异常、写任意 systemPrompt。

## 修复方案（已实施）

新建 `src/core/mcpBridge-validate.ts`（声明式意图载荷规格表 + 通用底线），dispatch 入口一行接入：

1. **通用底线**：payload 必须为 null/undefined 或普通对象（防标量/数组注入），56 个意图全覆盖；
2. **字段规格表**（30+ 意图登记）：required/类型/可选语义（'?'+null 放行以兼容 patch 置空），嵌套规格递归——重点覆盖 `agent:round_update.patch.segments: 'a?'`（渲染炸弹向量）与 `agent:ui_create`（AgentUpsertInput 全字段）；
3. 未声明字段不拦（前向兼容）；类型不符 throw → 信封 `ok:false` 返回给外部客户端；
4. 补充：新增意图时应同步登记载荷形状（模块头注释已注明）。

## 验证

畸形 payload 被结构化拒绝（对齐 tool_contract_probe 探针预期）。
