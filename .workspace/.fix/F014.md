# F014 · pipeline expect panic 击穿 run 终态写入

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.14
- 位置：`src-tauri/src/agent/engine/pipeline.rs:299`
- 级别：P1 严重·可靠性
- 状态：**待修复**

## 问题与影响

graph.task_to_plan(id).expect(...) panic 直接 unwind 出 spawn 任务（全仓 catch_unwind 0 次）→ emit_task_error 与 finalize_run_summary 都不执行 → end_time 留 NULL，前端整轮显示「进行中」直到重启。

## 修复方案

task_to_plan 返回 None 时 continue；外层包装 tokio::spawn + JoinError 检查把 panic 转成正常错误终态。

## 验证

注入 panic 场景下 run 仍以 error 终态收场、end_time 落库。
