# F012 · pause_checkpoint 缺状态守卫——终态可回退成 running

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.12
- 位置：`src-tauri/src/agent/squad/squad_orchestrator.rs:314、:311-341`
- 级别：P1 严重·正确性
- 状态：**待修复**

## 问题与影响

外部 Resume 与 cancel 并发时，UPDATE status='running' 可能在另一协程写入 cancelled 之后执行 → 终态被非法回退，此后无人写终态 → 永久 running 僵尸。

## 修复方案

改 UPDATE ... SET status='running' WHERE id=? AND status='paused'；finish_squad_session 加 AND status NOT IN ('done','failed','cancelled') 做 CAS 保护。

## 验证

并发 resume/cancel 压测无僵尸状态；终态不可被回退。
