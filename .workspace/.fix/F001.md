## 问题与影响

127.0.0.1 监听无任何 token 校验，tools/call 直接分发；全文 grep Authorization/Bearer 零命中。本机任意进程甚至网页 fetch 即可 agent_run_task（指定任意 workspace）、**agent_submit_approval 代用户批准**（击穿整个 HITL 边界）、agent_get_run_trace 读全部思考链。

## 修复方案

启动生成 256-bit token 存 OS keyring；客户端必须带 Authorization: Bearer，未授权 401；token 缺失时默认不启动监听；校验 Origin 白名单。

## 验证

无 token curl 返回 401；带 token 全功能正常；确认鉴权中间件代码存在。
