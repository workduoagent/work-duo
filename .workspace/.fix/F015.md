# F015 · 成员超时硬 drop 留半行 JSON——图节点永久丢失

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.15
- 位置：`src-tauri/src/agent/squad/squad_orchestrator.rs:3333-3365、graph.rs:979-990`
- 级别：P1 严重·可靠性
- 状态：**待修复**

## 问题与影响

timeout 到点直接 drop 内层 future，graph.snapshot 被跳过；append_line 是两次 write_all（line 与 \n 分开）——中间被 drop 产生半行 JSON，load_nodes 对解析失败行 warn 后跳过 → 该节点永久丢失，topo_ready 认为该步不存在走死锁分支。

## 修复方案

append_line 改单次 write_all(format!("{line}\n"))；archive_handoff_to_inbox 的 fs::copy 直写改「写 .tmp → rename」原子替换。

## 验证

超时注入后 graph 文件无残行；节点不丢。
