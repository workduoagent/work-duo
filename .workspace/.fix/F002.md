# F002 · run_python_script / run_node_script 绕过沙箱全链路

- 来源：[20261002 全项目走查](./20261002-走查报告原文.md) §1.2
- 位置：`src-tauri/src/lib.rs:180/188；mamba_manager.rs:1274、bun_manager.rs:662`
- 级别：P0 致命·安全
- 状态：**待修复**

## 问题与影响

作为 Tauri command 暴露，script_path 前端直传仅 exists() 校验——无 PathGuard、无 allow_sandbox、无 RequireApproval。与受控入口 run_python_in_sandbox（走 with_sandbox_guards + PathGuard + 审批）是两个不同函数。叠加 CSP null，渲染层任意注入即可执行本机任意 Python/Node。

## 修复方案

去掉 #[tauri::command] 降为 pub(crate)；若前端必须可见，复用 run_python_in_sandbox 全套守卫。

## 验证

前端 invoke 该命令不可达，或走守卫路径时弹审批卡。
